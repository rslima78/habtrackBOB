# Modo Monge — Habit Tracker Gamificado 🧘⚔️

Um aplicativo web responsivo e gamificado focado em **autocontrole, consistência diária e evolução de personagem**.

Transforme hábitos reais em missões de RPG pessoal:
- 🏃 **Treinos & Corridas**: registre caminhadas (+20 XP) e corridas (+40 XP) com metas semanais.
- 📚 **Leitura**: registre páginas lidas (+20 XP), estante de livros virtual e metas diárias.
- 💰 **Orçamento**: controle de gastos diários com limites, categorias e alertas motivadores.
- 🍔 **Alimentação**: sequências de autocontrole alimentar (😎 Controlado, 😐 Parcial, 💥 Deslize sem culpa).
- 🎯 **Subobjetivos**: crie micro-missões livres com recompensas personalizadas de XP.
- 📅 **Calendário**: mapa de calor mensal com raio-x de todas as atividades diárias.
- 📊 **Estatísticas**: gráficos por período (Semana, Mês, Ano) e sequências.
- 🏆 **Conquistas**: galeria com 12 medalhas desbloqueáveis.
- 📱 **100% Local & PWA**: dados salvos offline no celular, com opção de instalar na tela inicial.

---

## 🚀 Como Executar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Expor na rede local para acessar do celular
npm run dev -- --host
```

---

## 🛠️ Tecnologias Utilizadas

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** (Tema Gamificado com sombras e cores vibrantes)
- **Lucide Icons**
- **Web Audio API** (Sons e fanfarras de arcade sintetizados nativamente)
- **Canvas Confetti** (Efeitos de comemoração no Level Up)
- **LocalStorage** (Persistência 100% offline no dispositivo)
